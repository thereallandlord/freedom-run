# Freedom Run — игра про выход из денежной рутины

Настолка на 2–6 игроков: нарасти пассивный доход выше расходов, вырвись из
Круга и мчись к мечте. Свой движок, свой интерфейс.

**Три режима на выбор:**

| Режим | Что внутри |
|---|---|
| 🇷🇺 **Россия · халяль** (по умолчанию) | рубли, российские зарплаты и объекты, **рассрочка и инвестор вместо процентных кредитов**, партнёрский бизнес как класс актива |
| Уругвай | доллары, оригинальная колода из разбора |
| Классическая | доллары, классические кондо и франшизы |

RU-режим собран по итогам разбора живых партий: рубли, российские зарплаты и
объекты, финансирование без процентов.

## Что уже работает

**Полный цикл партии.** Круг → выход на Полосу свободы → победа мечтой или доходом.

- 2–6 игроков на одном устройстве, любое место можно отдать боту
- 4 уровня ботов, каждый — набор из 14 коэффициентов
- Три колоды: RU (142 карты + своё поле), Уругвай, классика
- 12 профессий РФ + 12 оригинальных, 12 мечт в каждом режиме
- Акции покупает и продаёт **любой игрок Круга**, пока карта на столе
- Предложения рынка 60–500%, сплиты, разовые выплаты, повышения зарплаты
- Благотворительность (2 кубика на 3 хода / 3 кубика на Полосе)
- Увольнение, питомцы, банкротство с продажей активов за полцены
- Полоса свободы: инвестиции, рисковые проекты, налоговая, иск, развод
- **Победитель выходит, остальные доигрывают** — как в живой игре
- Отмена хода, автосохранение, журнал партии

### Что даёт халяль-режим

- **Процентных кредитов нет вообще.** Кнопка займа исчезает, банк превращается
  в раздел «Финансы» с досрочным погашением.
- **Рассрочка** — долг на объекте фиксированный, без процентов; крупная трата
  делится на 10 равных платежей.
- **Инвестор** — на крупную недвижимость, которая не по карману: он вносит взнос,
  забирает половину потока и половину выручки от продажи.
- **Партнёрский бизнес** — стартовый пакет 28 900 ₽ / расширенный 86 700 ₽,
  поток растёт с каждой зарплатой до потолка (структура приводит людей).
  Карта рынка «Автопромоушен закрыт!» платит владельцам 150 000 ₽.
- **Развод забирает половину**, а не всё.

## Архитектура

Игра **event-sourced**: состояние не хранится, хранится журнал событий, из
которого оно пересобирается. Это решение взято из оригинала — оно правильное.

```
src/engine/          чистый TypeScript, без React
  types.ts           модель данных
  events.ts          словарь событий (кошелёк + стол)
  ledger.ts          формулы: доходы, расходы, поток, условие выхода
  applyEvent.ts      редьюсер кошелька одного игрока
  table.ts           редьюсер стола: ходы, клетки, карты, банкротство
  bots.ts            ИИ по профилям сложности
  rng.ts             mulberry32 — детерминированный ГПСЧ
  data.ts            загрузка данных и локализация
  selftest.ts        прогон партий без интерфейса

src/ui/              React
  useGame.ts         состояние, сохранение, откат, водитель ботов
  Setup.tsx          выбор игроков, профессий, мечт
  Game.tsx           экран партии
  Board.tsx          два кольца
  PlayerPanel.tsx    отчёт о доходах
  CardModal.tsx      разбор карт и клеток
  BankModal.tsx      кредиты и долги
  Dropdown.tsx       свой выпадающий список (нативный select не используем)

src/data/            JSON из разбора оригинала
```

Что даёт event sourcing бесплатно:

- **откат хода** — проигрываем журнал без последнего события;
- **сохранение** — в localStorage лежит только сетап и список событий;
- **онлайн** — по сети надо гонять те же события, ничего больше;
- **реплей и разбор партии** — журнал уже есть.

Кубики попадают **внутрь события**, а не берутся из генератора при
проигрывании — иначе воспроизведение разошлось бы с оригинальной партией.

## Ключевые правила и формулы

```
пассивный доход = дивиденды + аренда + поток бизнесов
всего доходов   = зарплата + пассивный доход
всего расходов  = статьи расходов + платёж по кредиту + питомцы
поток в месяц   = всего доходов − всего расходов
выход из Круга  = пассивный доход > всего расходов   (строго больше)
выкуп при выходе = пассивный доход × 100
цель Полосы     = +$150 000 нового дохода в месяц
```

| Операция | Цена |
|---|---|
| Банковский кредит | $100/мес за каждую $1 000 (10%) |
| Трата на кредитку | +3%/мес от суммы, навсегда |
| Благотворительность | 10% дохода → 2 кубика на 3 хода |
| Увольнение | месяц расходов + пропуск 2 ходов |
| Налоговая / иск | половина наличных |
| Развод | все наличные |
| Продажа банку при банкротстве | половина первого взноса |
| Чужая мечта | +100% от базовой цены за каждое посещение |

## Чем это отличается от оригинала

- Код и интерфейс написаны заново, не скопированы.
- «Дети» переименованы в питомцев — так это и подавалось в оригинале
  (в коде поле называлось `children`, а в игре появлялась собака).
- Нет графики карт: у оригинала ~300 авторских иллюстраций.
- Нет онлайна: заложена архитектура под него, но синхронизация не подключена.
- Нет 18+ слоя, который был в оригинале скрыт под паролем.
