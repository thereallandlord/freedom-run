# Вторая площадка: Vercel

Зачем: **Railway из России без VPN не открывается**. Режут не наш домен, а всю
их пограничную сеть целиком — сменой домена это не лечится, проверено. Vercel
из России открывается, поэтому игра живёт на двух адресах сразу.

Третий адрес — GitHub Pages (`thereallandlord.github.io/freedom-run`) — уже
работает и обновляется сам при каждом push. Он статический: на нём нет разбора
партии и кабинетов, только сама игра.

## Что уже сделано в репозитории

| Файл | Что делает |
|---|---|
| `vercel.json` | сборка `npm run build` → `dist`, переброс `/auth-back`, все неизвестные адреса на `index.html` |
| `api/[[...path]].mjs` | переходник: отдаёт запросы тому же обработчику, что и свой сервер |
| `server/index.mjs` | обработчик вынесен в `handler` и экспортируется; порт занимается, ТОЛЬКО когда файл запущен напрямую |

🔴 Своей логики у Vercel нет намеренно. Оба хостинга зовут **один и тот же
код** — иначе две копии игры начнут вести себя по-разному, и понять почему
будет почти невозможно.

## Что нужно сделать руками (один раз)

1. На vercel.com → **Add New → Project** → подключить GitHub → выбрать
   репозиторий `thereallandlord/freedom-run` → **Import**.
2. Настройки сборки не трогать: их берёт `vercel.json`.
3. **Environment Variables** — перенести из Railway (сервис игры):
   - `OPENROUTER_API_KEY` — без него не работает разбор партии
   - `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_KEY` — кабинеты и история партий
   - `AUTH_BACK_EXTRA` — сюда вписать адрес, который выдаст Vercel
     (например `https://freedom-run.vercel.app`), иначе вход через Google
     вернёт человека не туда
   - по желанию: `DEBRIEF_MODEL`, `DEBRIEF_PER_HOUR`, `DEBRIEF_PER_DAY`
4. **Deploy**.
5. В Supabase → Authentication → URL Configuration → **Redirect URLs** добавить
   адрес Vercel со звёздочкой: `https://<адрес>.vercel.app/**`.
   🔴 Без пути со звёздочкой Supabase молча подменяет адрес возврата на
   корневой — человек, войдя из игры, окажется в другом сервисе.
6. Проверить по адресу Vercel: `/api/health` должен отдать `{"ok":true}`,
   игра — открыться, вход через Google — вернуть обратно в игру.

## Что помнить про тариф

Бесплатный Hobby запрещает **коммерческое** использование. Пока игра
показывается своим и обкатывается — это не оно. Как только за неё начнут
платить, нужен Pro (20 $ в месяц на человека в команде).

## Известное ограничение

Ограничитель на разбор партии считает обращения **в памяти процесса**. У своего
сервера процесс один, и счёт честный. У Vercel каждый запрос может попасть в
свежий экземпляр, поэтому там ограничитель слабее — он режет только частые
повторы подряд. Если разбором начнут злоупотреблять, счёт придётся вынести в
базу.
